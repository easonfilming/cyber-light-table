# 赛博观片台

把照片按项目整理起来，每 40 张（最后一批不满 40 张也算一卷）合成一张
**"胶卷展开"风格的总览图**。打开程序是一堵项目卡片墙，点进去是观片台 ——
开灯才看得见照片，还能拿观片器凑近看细节。

## 运行

**双击 `启动赛博观片台.bat`** —— 最省事，不会弹黑框。

或者在命令行里：

```
python main.py
```

**不需要安装任何东西** —— 只用 Python 自带的 tkinter 和 Pillow。
（本机已确认：Python 3.12.6 + Pillow 12.2.0）

程序启动时会告诉 Windows 自己处理高 DPI，所以在 125% / 150% 缩放的屏幕上
界面是清晰的，不会被系统拉伸得发虚。

## 打包成 exe

想发给别人、或者自己当个正经软件用，可以打包成单文件 exe：

**双击 `打包.bat`**，或者在命令行里：

```
python build_exe.py
```

产物在 `dist/`：

```
dist/
├── 赛博观片台.exe    约 19 MB，双击就能跑
└── 使用说明.txt          给用户看的说明
```

对方**不需要装 Python**，整个 `dist` 文件夹拷过去就能用。

几个说明：

- 打包过程会建一个**临时虚拟环境**（`_build/venv`），不碰你现有的 Python
- 第一次打包要联网下载 PyInstaller（约 60 MB），之后再打就快了
- `_build/` 有 60 多 MB，是中间产物，**可以随时删掉**（下次打包会重建）
- 图标是脚本用 Pillow 现画的（一只柯达黄暗盒 + 片头），改 `build_exe.py`
  里的 `make_icon()` 就能换
- exe 带了版本信息，在文件「属性 → 详细信息」里能看到

> 单文件 exe 每次启动要先把内容解压到临时目录，**冷启动会慢 2-4 秒**。
> 嫌慢的话可以把 `build_exe.py` 里的 `--onefile` 改成 `--onedir`，
> 打出来是个文件夹，启动快但得整个文件夹一起拷。

## 用法

左边是常驻侧边栏，四个入口：

### 项目

- 每个项目一张卡片，**封面就是生成好的胶卷图**（还没生成过就显示占位块）
- 点卡片进项目；**右键**卡片可以**打开 / 重命名 / 删除**
  - **重命名**会把项目文件夹一起改名。万一文件夹里有文件被别的程序占着
    （资源管理器预览、杀软扫描等）会改失败，那就先关掉那些再试
- 点 **＋ 新建项目** 建新项目
- 右上角有**搜索框**，项目多了按名字筛

### 暗盒

**暗盒设计器** —— 自己设计暗盒并保存，之后在项目里直接选用。

- 左边列出所有暗盒：三个内置（柯达黄 / 富士绿 / 伊尔福黑白）+ 自己保存的
- 中间是**大预览，改任何一项立刻重画**
- 能改：名称、标签文字、副标题、标签颜色、筒身颜色、文字颜色（可自动配对比色）
- 改动**自动保存**，不用点保存按钮
- 内置的三个不能改也不能删，但可以「复制一份」出来改

### 图库

**胶卷图库** —— 把所有项目生成过的胶卷图汇总成一面墙。

- 每张卡片标着「项目名 + 第 n/m 卷」，卡片上的 **去项目** 直接跳到对应项目
- 点卡片本身弹出**全屏灯箱窗口**：能开灯、上观片器、左右翻卷、导出这张
- **在灯箱里点某一格，直接打开那张照片的原图**
- 右上角 **全部导出…** 一次导出所有项目的所有卷
- 按 `←` `→` 翻卷，`F5` 开关灯，`Esc` 关闭

### 设置

- **项目目录** —— 项目文件夹都放这儿，更改后重启仍然记得
- **胶卷图存放位置** —— 生成的胶卷图放哪儿：
  - 默认「**跟着项目走**」，存在 `<项目文件夹>/strips/` 里 —— 项目是自包含的，
    整个文件夹拷走不会丢东西
  - 也可以指定一个总目录，所有项目的胶卷图都放那儿、按项目名分子文件夹
  - 改了之后**之前生成的还在原处，两边都会照常显示**，不会丢
- **导出路径** —— 批量导出时默认填的目标文件夹
- **新建项目的默认值** —— 每卷张数、每行张数、显示方式、暗盒
- **观片器** —— 镜外压暗的深浅（拖到 0 就是完全不压暗）
- **缩略图缓存** —— 显示占用大小，可一键清理（不影响照片和已生成的胶卷图）
- **关于** —— 简短的使用说明

### 进项目之后

左边挑照片，右边是观片台。

| 操作 | 说明 |
|---|---|
| **添加照片** | 可多选；照片**复制**进项目文件夹，原图不受影响。重复导入会自动跳过 |
| **拖拽导入** | 直接从资源管理器把照片**拖进窗口**也行 |
| **删除选中** | 只删项目里那份，原图不动（Delete 键也行） |
| **生成胶卷图** | 按每卷张数自动分卷，生成后自动载入观片台（F5 也行） |
| **项目设置…** | 改这个项目的每卷张数 / 每行张数 / 显示方式 / 暗盒，带「会分成几卷」的实时提示 |
| **暗盒** | 挑暗盒样式；选「去设计暗盒…」会跳到设计器 |
| **导出当前卷 / 批量导出…** | 批量导出会把这个项目的所有卷一次导出 |
| 双击缩略图 | 弹出大图预览（Esc 关闭，也可用系统查看器打开） |
| **在观片台上点某一格** | 直接打开那张照片的原图（得先开灯） |
| Ctrl + 点击 | 加选多张 |
| Shift + 点击 | 从上次点的那张连选到这张 |
| Ctrl + A / Ctrl + I | 全选 / 反选 |
| **右键照片** | 全选 / 反选 / 移到最前 / 移到最后 / 删除选中 |
| 拖动缩略图 | 调整顺序（自动切回"导入顺序"查看） |
| 排序 | 导入顺序 / 文件名 / 拍摄时间（读 EXIF） |
| 显示 | 竖图转90° / 完整显示 / 填满画幅（见下） |

### 观片台

- **初始是关着灯的** —— 只看得见胶片的剪影，看不清内容
- 点右下角 **开灯**，灯箱亮起，照片才显示出来
- 开一次就一直亮着，翻卷、换项目、切页面都不熄；再按一下才关掉
- 滚轮缩放，空白处按住拖动平移

### 观片器

- 右侧栏挑倍率：**1× / 2× / 4× / 8×**
- 选中的观片器出现在灯箱正中，**按住左键拖动、松开放下**
- 透过镜片看的是**原始像素**：4× 就是 1 个图像像素放大成 4 个屏幕像素，
  和真的观片器一样，跟当前视图缩放无关
- 倍率越高镜片越小（跟真观片器一样）
- 再点一次同一个倍率，或点 **收起**，就把观片器拿开

## 暗盒样式

生成图左上角是一只立起来的 135 暗盒：**深色塑料筒身 + 整圈包住的彩色标签**，
顶上露出一截卷轴头，片头从侧面的出片口拉出来。

三个内置样式：柯达黄（黄底黑字）、富士绿（绿底白字）、伊尔福黑白（白底黑字）。
想自己设计就去侧边栏的 **暗盒设计器** —— 能改标签文字、副标题、标签颜色、筒身颜色、
文字颜色，保存后在项目里直接选用。自定义选的通常是**标签**颜色，
筒身默认是深色塑料壳，跟真胶卷一样。

## 显示方式

竖构图照片怎么放进横向画幅，有三种处理：

| 选项 | 效果 |
|---|---|
| **竖图转90°**（默认） | 竖构图照片先转 90° 再放进画幅 —— **不丢内容，也不留黑边**。照片顶部朝左，看的时候头往左偏 |
| 完整显示 | 不旋转，整张照片都看得见，两侧留深色边 |
| 填满画幅 | 居中裁剪填满，画幅最统一，但竖构图会被裁掉两侧 |

## 文件都放哪了

项目默认存在 `图片\FilmProjects\`（可在项目墙上改）：

```
FilmProjects\
└── 我的项目\
    ├── project.json      项目元数据（照片清单、设置、暗盒选择）
    ├── photos\           复制进来的原图
    │   └── .thumbs\      缩略图缓存 + 卡片封面缓存（可随时删，会自动重建）
    └── strips\           生成的胶卷总览图
        ├── strip_001.jpg
        ├── strip_002.jpg
        └── strip_003.jpg
```

整个项目文件夹可以直接拷贝/备份，不依赖原图。

> 如果在设置里改了「胶卷图存放位置」，胶卷图就跑到那个总目录下、按项目名分子文件夹了，
> 项目文件夹里不再有 `strips/`。**这时候项目就不再是自包含的**，拷项目文件夹不会带上胶卷图。

另外，程序的配置（项目目录、两个输出路径、新建默认值、观片器压暗、自己保存的暗盒）存在：

```
%APPDATA%\CyberLightTable\config.json
```

放在这儿而不是项目目录里，这样改项目目录时暗盒库不会跟着丢。
具体路径在 **设置** 页能看到，也有一键打开。

## 调整每卷张数

- **新建项目的默认值** —— 在 **设置** 页里改（每卷张数、每行张数、显示方式、暗盒）
- **单独改某个项目** —— 进项目后点工具栏的 **项目设置…**，
  改的时候会实时提示「会分成几卷、每卷几列几行」

图幅尺寸会自动跟着算：每行 8 张时单卷是 3080 × 2160 像素。

## 试试看

生成一批测试照片（100 张，含横构图、竖构图和带 EXIF 旋转标记的）：

```
python make_test_photos.py
```

会生成到 `图片\test_photos\`。用它们建个项目就能看到 40 / 40 / 20 三卷的效果。

## 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 主程序：窗口骨架、侧边栏、页面路由、工作区、照片网格、项目设置 |
| `home.py` | 项目卡片墙（带搜索） |
| `designer.py` | 暗盒设计器 |
| `gallery.py` | 胶卷图库 + 全屏灯箱窗口 |
| `settings_page.py` | 设置页（含关于） |
| `exporter.py` | 批量导出 |
| `photoview.py` | 看单张照片原图的弹窗 |
| `dropfiles.py` | 从资源管理器拖照片进来（Windows 专有，失败就静默不启用） |
| `lighttable.py` | 观片台 + 观片器 + 观片台面板（工作区和灯箱共用） |
| `strip.py` | 胶卷图渲染引擎（纯 Pillow，可单独调用） |
| `canister.py` | 胶卷暗盒的绘制 + 暗盒库的解析 |
| `appconfig.py` | 应用配置 + 暗盒库的读写 |
| `theme.py` | 米色主题：配色、字体、控件外观 |
| `project.py` | 项目数据模型（project.json 读写、照片导入/删除/排序） |
| `make_test_photos.py` | 生成测试照片 |
| `build_exe.py` | 打包脚本（生成图标、版本信息、调 PyInstaller） |
| `使用说明.txt` | 给最终用户看的说明，打包时会拷进 `dist/` |

`strip.py` 可以单独当库用：

```python
from strip import render_strip, split_into_strips

chunks = split_into_strips(list_of_paths, 40)
img = render_strip(chunks[0], start_number=1, cols=8, project_name="我的项目",
                   strip_index=1, strip_total=len(chunks),
                   fit_mode="rotate", canister="kodak")
img.save("strip_001.jpg", quality=92)
```
